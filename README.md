# 🎲 Ciekawostnik / Facts

Lekka, minimalistyczna strona internetowa serwująca losowe ciekawostki ze świata natury, zwierząt, roślin i człowieka. Projekt stworzony w czystym HTML, CSS i JavaScript.
---

## ✨ Funkcje

- 🎲 **Losowanie ciekawostki:** Jedno kliknięcie losuje kartę z losowym faktem i zdjęciem.
- 🏷️ **Filtrowanie po tagach:** Kliknij w dowolny hashtag (np. `#ssaki`, `#zebra`), aby zobaczyć wszystkie ciekawostki powiązane z danym tematem.
- 🌐 **Wielojęzyczność (PL / EN):** Wsparcie dla języka polskiego i angielskiego z zapamiętywaniem wyboru w przeglądarce.

---

## 🛠️ Użyte technologie

- **HTML5** (Semantyczna struktura)
- **CSS3** (Flexbox, zmienne CSS, animacje `@keyframes`, responsywność)
- **JavaScript (Vanilla JS)** (Dynamiczne losowanie, filtrowanie, obsługa słownika i `localStorage`)
